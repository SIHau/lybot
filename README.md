# 立法院查詢 Discord 機器人（lybot）

用 Discord 斜線指令查詢立法委員資料、選區代表與立法院議案進度。資料來自 [立法院 API（LYAPI v2）](https://ly.govapi.tw/v2/)。

## 功能

| 指令 | 說明 |
| --- | --- |
| `/立委 姓名` | 查詢現任或歷任（第 1～11 屆）立法委員的屆期、政黨、選區、委員會紀錄與照片 |
| `/立委 黨籍` | 依黨籍列出立法委員，可再依屆數、選區篩選 |
| `/選區` | 依縣市或鄉鎮關鍵字查詢該選區的現任立委 |
| `/提案` | 依關鍵字或委員姓名查詢議案，顯示案由、提案人、議案狀態與最新進度 |

查詢結果有多筆時，會以分頁卡片顯示，用「上一頁／下一頁」按鈕切換（2 分鐘後按鈕自動停用）。

## 環境需求

- Python 3.10 以上
- 套件：`discord.py`、`aiohttp`、`python-dotenv`

## 安裝與設定

### 1. 建立 Discord 機器人

1. 到 [Discord Developer Portal](https://discord.com/developers/applications) 建立一個 Application。
2. 在左側 **Bot** 頁面按 **Reset Token**，複製機器人的 Token。
3. 在 **OAuth2 → URL Generator** 勾選：
   - Scopes：`bot`、`applications.commands`
   - Bot Permissions：`Send Messages`、`Embed Links`
4. 用產生的網址把機器人邀請到你的伺服器。

### 2. 安裝套件

```bash
pip install discord.py aiohttp python-dotenv
```

### 3. 設定 Token

在 `lybot.py` 同一個資料夾建立 `.env` 檔案：

```
DISCORD_TOKEN=你的機器人Token
```

> `.env` 已列在 `.gitignore`，不會被提交到 GitHub。請勿把 Token 公開。

### 4. 啟動

```bash
python lybot.py
```

啟動時會先從 API 載入全部立委名冊（約 1600 多筆），需要 10～20 秒。成功後會看到：

```
✅ [LYAPI] 成功載入全體委員資料共 1656 筆（現任第 11 屆: ...）
🚀 機器人已成功啟動！登入身分：...
```

斜線指令第一次同步到 Discord 可能需要幾分鐘才會出現。

## 指令使用方式

### `/立委 姓名`

- `name`（必填）：委員姓名，可輸入部分姓名，例如 `黃國昌`、`王金平`
- `status`（選填）：
  - `現任委員 (第11屆)`（預設）：只查第 11 屆且未離職的委員
  - `歷任委員 (歷屆全部 1~11屆)`：查所有屆期，結果依屆期由新到舊排列；已離職者會標註「已離職」

範例：`/立委 姓名 name:王金平 status:歷任委員`

### `/立委 黨籍`

依序填入三層條件，每一層的下拉選單只會列出符合前面條件的選項：

1. `party`（必填）：黨籍。下拉選單列出歷屆出現過的所有政黨（含「無黨籍」），依人數排序。也可以輸入簡稱：

   | 簡稱 | 對應黨籍 |
   | --- | --- |
   | `民進黨` | 民主進步黨 |
   | `國民黨` | 中國國民黨 |
   | `民眾黨` | 台灣民眾黨 |
   | `時力` | 時代力量 |
   | `基進` | 台灣基進 |
   | `台聯` | 台灣團結聯盟 |

   其他簡稱可在 `lybot.py` 的 `PARTY_ALIASES` 新增。
2. `term`（選填）：屆數。不填則查詢歷屆
3. `area`（選填）：選區，例如 `全國不分區`、`臺北市第1選舉區`。輸入部分名稱也可以，例如 `臺北市` 會列出所有臺北市選區的委員

結果依屆期由新到舊列出，格式為「第 N 屆｜姓名｜選區」，每頁 20 筆；已離職者會標註「（已離職）」。

範例：`/立委 黨籍 party:民進黨 term:11 area:全國不分區`

### `/選區`

- `district`（必填）：輸入時會出現下拉選單，請從選單中選擇選區，例如輸入 `竹北` 或 `板橋`

> 選區資料目前是寫在程式裡的部分清單（`DISTRICT_DATA`），並非全國所有選區。需要其他選區時，請直接在 `lybot.py` 的 `DISTRICT_DATA` 新增。

### `/提案`

- `keyword`（必填）：
  - 輸入**委員姓名**（例如 `林月琴`）：列出該委員提出的議案
  - 輸入**其他關鍵字**（例如 `教保服務人員條例`）：以完整詞組搜尋議案名稱、案由、說明與提案單位

結果依最新進度日期排序，最多顯示 10 筆。卡片標題可點擊，連到立法院議事暨公報資訊網的議案頁面。

## 從舊版升級

`/立委` 已改為指令群組，原本的 `/立委 name:...` 請改用 `/立委 姓名 name:...`。更新程式並重新啟動後，Discord 可能需要幾分鐘才會顯示新的指令結構；若舊指令仍出現，重新整理 Discord（`Ctrl+R`）即可。

## 資料與紀錄

- **立委名冊**：啟動時載入並快取在記憶體中，重新啟動機器人才會更新。
- **查詢紀錄**：每次成功的 `/提案` 查詢會寫入同資料夾的 `reports.db`（SQLite），記錄時間、使用者與關鍵字。
- **API 限流**：API 對過快的請求會回傳 HTTP 429，機器人會自動等待並重試（每頁最多 5 次）。若終端機出現「以下頁面載入失敗」，代表部分歷任資料沒有載入，重新啟動即可。

## 注意事項

- 程式對 API 連線關閉了 SSL 憑證驗證（`ssl=False`），以避免部分本機環境缺少憑證而報錯。若要在正式環境使用，建議改用 `certifi` 提供的憑證。
- 現任屆期寫在程式中的 `CURRENT_TERM = 11`，改選後請更新此數值。
